# AI Studio 0.1.0

AI Studio 0.1.0 是面向 Windows 的本地 AI 创作工作台。它通过本机 ComfyUI
执行图片和视频工作流，并把任务、项目、预设和生成素材保存在本机。

这是 AI Studio 的首个 0.1.0 公开版本。

## 本版内容

- 简体中文的创作、资产库、任务、项目和工作流界面。
- ComfyUI 工作流导入、能力检查、输入/输出映射和本地运行状态展示。
- 图片、视频、参考图、源视频和源音频的本地素材管理。
- 持久化任务与生产队列，支持暂停、恢复、重启恢复、失败跳过和失败重试。
- 生成结果自动进入项目资产库，支持预览、归档、恢复和删除。
- 设置页诊断包导出，用于本地问题排查。
- Kera2 文生图工作流已完成本地实机验证。
- MiniMax H3 参考图生视频提供适配 16 GB 显存的安全运行档位。

## 使用前提

1. 在本机安装并启动 ComfyUI。
2. 在 ComfyUI 中准备工作流所需的模型和自定义节点。
3. 启动 AI Studio，在工作流页导入或选择可用工作流后开始创作。

AI Studio 0.1.0 不包含模型文件、ComfyUI 安装包或用户工作流。MiniMax H3
的 16 GB 显存验证档位限制为约 0.1 MP、1–5 秒、4 步、单个活动任务；不要在该显存档位
自动提高分辨率、时长或并发。Wan、Flux、Qwen 等其他模型不在本版本的正式运行承诺内。

## 数据与隐私

项目、任务、预设、提示词和生成素材按应用功能保存在本机数据目录。应用不要求登录，
本版本不提供云端同步、在线模型市场、自动更新、遥测或远程日志上传。诊断包只导出诊断摘要、应用日志和
说明文件，不包含数据库、工作流源码、Recipe、Manifest、绝对路径或提示词内容；分享
诊断包前仍应由用户自行检查其内容。

## 安装、升级和卸载

- 推荐使用 Windows 安装包进行安装。
- 0.1.0 使用独立的本地数据目录；升级或卸载应用不会删除项目数据。
- 卸载后重新安装，应用可以继续读取原有项目、任务、工作流和资产。
- 同一时间只运行一个 AI Studio 实例；再次启动会把已有实例置于前台。
- 关闭窗口时如果仍有生成任务或生产队列，应用会显示安全退出提示，选择继续运行
  不会取消任务。

## 已知限制

- ComfyUI 离线时 AI Studio 仍可打开和查看本地数据，但无法提交新的生成任务。
- 生成速度和可用显存取决于本机 GPU、模型和 ComfyUI 配置。
- MiniMax H3 的高分辨率、长时长和多并发运行需要单独的显存档位验证。
