# AI Studio 2.1 M2-1 — Runs recovery semantics

## Scope

Parent: `b6d60ad1cf6906531fb81123fba8e8eea2835976`, completed M1.
This checkpoint explains existing recovery capabilities, not a new recovery system.
Prompt/asset search, pagination, media maintenance and M2-2 are out of scope.

`runRecoveryPresentation(ProductRun)` is pure presentation. Retry requires both
backend `availableActions: RETRY` and nonempty `recoverability.retryItemIds`.
Input-edit guidance uses `reviewRequired > 0` or `EDIT_INPUT`. Neither error text,
phase, raw codes nor technical logs determine actions. The helper performs no
navigation, mutation, IPC or store writes.

- **重试原运行的可恢复失败项** displays the authoritative count and explains that
  original item snapshots—not unsubmitted Create edits—are used. History remains.
  The unchanged controller sends exactly `recoverability.retryItemIds` to run.retry.
- **编辑这些输入并创建新运行** remains attached to a specific RunInput, not an
  ambiguous run-level selector. It invokes the unchanged reuse controller to find
  the exact selectionRef and load a scoped Create intent. Only an explicit Generate
  creates a new run. A missing exact generator fails rather than switching to a
  recommended, latest or similarly named generator.
- Mixed retry/edit failures show both paths. With no typed recoverable/editable
  failure facts, the explanation admits unclassified causes and offers input/advanced
  diagnostics, not a fake retry or guessed required edit.
- PARTIAL remains **部分完成**. PAUSED remains **已暂停**, with **继续运行** only
  when backend START is available. QUEUED/RUNNING/SUCCEEDED do not force a recovery
  warning. CANCELLED does not itself grant retry.
- Completed/actual results remain visible even for FAILED. Preservation text does
  not merge execution success, asset existence, review approval and shot selection;
  RunResults still presents all four independent facts, including missing files.
- Historical incomplete-input warnings remain explicit. Technical identifiers stay
  in the existing collapsed technical details.

No RunsController, RunResults, polling, Studio Store, router, product DTO, IPC,
Rust, queue/task authority, review OCC, shot selection or generator identity changes.
No automatic retry/review/selection/start/generation. No telemetry or new dependencies.
Version stays `2.0.0-personal`; migration maximum=42, formal table count=71,
no 043, backup=v20. No tag/release/installer is created.
